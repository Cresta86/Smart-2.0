# Timbrature · Portale orari personale

Strumento personale per registrare timbrature, assenze, recuperi e trasferte direttamente nel browser.
Versione **2026.11.23.5**.

## Pubblicazione su GitHub Pages

1. Carica `index.html` (e, se vuoi, questo `README.md`) nella **radice** del repository.
2. In **Settings → Pages** scegli *Deploy from a branch*, ramo **main**, cartella **/ (root)**, e premi **Save**.
3. Dopo uno o due minuti apri il sito e controlla che in basso a destra compaia la versione 2026.11.23.5 (`Ctrl+F5` per ricaricare).

Tutto il programma (stile e script) è contenuto in `index.html`: non servono altri file o cartelle.

## Dati

I dati restano solo nel browser di chi usa il sito (`localStorage`). Usa **Azioni → Backup completo** per salvarne una copia e **Azioni → Ripristina backup** per recuperarla su un altro computer.

Lo strumento è un supporto personale e non sostituisce SAP, le autorizzazioni o le verifiche HR.
